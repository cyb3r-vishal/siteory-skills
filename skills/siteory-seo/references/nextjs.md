# Fixing SEO findings in Next.js

Covers the App Router (Next.js 13.4 through 16). Pages Router notes are at the end. Check the version in package.json first: Next.js 16 renamed `middleware.ts` to `proxy.ts` (the exported function is `proxy`), and from Next.js 15 `params` and `searchParams` are Promises that must be awaited.

Verify with a production build: `npx next build && npx next start` (http://localhost:3000). `next dev` renders differently and adds dev-only scripts.

## Titles and descriptions

`seo_missing_title`, `seo_duplicate_title`, `seo_title_quality`, `seo_missing_description`, `seo_duplicate_description`, `seo_description_quality`.

Set the site defaults once in the root layout, then give every page its own title and description:

```tsx
// app/layout.tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
  metadataBase: new URL("https://www.example.com"),
  title: { default: "Acme: invoicing for small agencies", template: "%s | Acme" },
  description: "Acme sends invoices, chases late payments and reconciles bank feeds for agencies with 2 to 50 people.",
};
```

```tsx
// app/pricing/page.tsx
export const metadata = {
  title: "Pricing for small agencies", // rendered as "Pricing for small agencies | Acme"
  description: "Three plans from $12 per month. Every plan includes unlimited clients, recurring invoices and bank reconciliation.",
  alternates: { canonical: "/pricing" },
};
```

For dynamic routes use `generateMetadata` and build the text from the same data the page renders:

```tsx
// app/blog/[slug]/page.tsx
import type { Metadata } from "next";

export async function generateMetadata({ params }: { params: Promise<{ slug: string }> }): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug); // same cached fetch the page uses
  return {
    title: post.title,
    description: post.excerpt,
    alternates: { canonical: `/blog/${slug}` },
    openGraph: { title: post.title, description: post.excerpt, images: [post.coverImage] },
  };
}
```

Notes:
- `title.template` applies to child segments only, and needs `title.default`. A title set in `page.tsx` is not templated by a template in the same segment's `layout.tsx`. Use `title: { absolute: "..." }` to skip the template.
- "Create Next App" and "Generated by create next app" are the create-next-app defaults in `app/layout.tsx`; Siteory flags them as template defaults (medium).
- Count the template suffix toward the 60-character title limit.

## Canonicals

`seo_canonical_other_host`, `seo_canonical_error_target`, `seo_canonical_conflict`.

- Set `metadataBase` in the root layout to the production origin. A relative URL in metadata without `metadataBase` is a build error.
- Set `alternates.canonical` per page, matching that page's own route. Do not put `alternates: { canonical: "/" }` in the root layout: every page that does not override it inherits it and declares the homepage as its canonical.
- Keep trailing slashes consistent with `trailingSlash` in `next.config`.
- Read the production origin from one place (for example `process.env.NEXT_PUBLIC_SITE_URL`), and make sure that variable is set in production. A wrong value there causes `seo_canonical_other_host`.

## noindex

`seo_noindex`: search for `robots:` in metadata and for `X-Robots-Tag` in `next.config` headers and `proxy.ts`.

```tsx
export const metadata = { robots: { index: false, follow: true } }; // only on pages that must stay out of search
```

A common bug is an environment check such as `robots: { index: process.env.VERCEL_ENV === "production" }` where the variable is not set on the production host. Vercel preview deployments send `X-Robots-Tag: noindex` themselves; that is expected.

## Viewport and language

- `seo_missing_viewport`: the App Router emits `<meta name="viewport" content="width=device-width, initial-scale=1">` automatically. If it is missing, look for a custom `<head>` in the root layout that replaced it, or a `viewport` export with an empty value. Customise it with `export const viewport: Viewport = { ... }`, not inside `metadata`.
- `seo_missing_lang`: set it on the root layout: `<html lang="en">`. With internationalised routes, set it from the locale param.

## Headings and images

- `seo_missing_h1`, `seo_multiple_h1`, `seo_skipped_headings`: headings live in components. Find the shared header component; a logo in `<h1>` on every page is the usual cause of multiple H1s.
- `seo_missing_alt`: `next/image` requires `alt`. Use a description for meaningful images and `alt=""` for decorative ones. Plain `<img>` tags need the same.

## Social metadata

`seo_missing_social`:

```tsx
export const metadata: Metadata = {
  openGraph: { title: "Acme", description: "...", images: ["/og.png"], type: "website" },
  twitter: { card: "summary_large_image" },
};
```

Or add `app/opengraph-image.png` (or a generated `opengraph-image.tsx`) and `app/twitter-image.png`; Next.js emits the tags. Relative image URLs resolve against `metadataBase`.

## robots.txt and sitemap

```ts
// app/robots.ts
import type { MetadataRoute } from "next";

export default function robots(): MetadataRoute.Robots {
  return {
    rules: [{ userAgent: "*", allow: "/", disallow: ["/api/", "/dashboard/"] }],
    sitemap: "https://www.example.com/sitemap.xml",
  };
}
```

```ts
// app/sitemap.ts
import type { MetadataRoute } from "next";

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const posts = await getPosts();
  return [
    { url: "https://www.example.com/", lastModified: new Date() },
    ...posts.map((post) => ({ url: `https://www.example.com/blog/${post.slug}`, lastModified: post.updatedAt })),
  ];
}
```

List only URLs that return 200 and are linked from the site; `seo_sitemap_unlinked` reports sitemap URLs that no crawled page links to. For more than 50,000 URLs use `generateSitemaps`.

## Broken internal links

`seo_broken_internal_links`: search for the target path in `href=` and `<Link href=` values. For moved pages add a redirect:

```ts
// next.config.ts
const nextConfig = {
  async redirects() {
    return [{ source: "/old-pricing", destination: "/pricing", permanent: true }];
  },
};
export default nextConfig;
```

Call `notFound()` for missing records so they return 404 instead of an empty 200 page.

## Slow homepage

`seo_slow_start` (checked on the deployed site): make the homepage static. Remove request-time APIs (`cookies()`, `headers()`, uncached `fetch`) from the root layout and home page, or move them into a Suspense boundary. Without Cache Components, `export const revalidate = 3600` keeps a page static with periodic refresh. With Cache Components (`cacheComponents: true`), mark the data functions with `'use cache'` and `cacheLife`.

## HTTPS

`seo_homepage_http`: hosts such as Vercel redirect to HTTPS automatically. Self-hosted: terminate TLS at the proxy (nginx, Caddy) and redirect port 80 to 443.

## Pages Router

Use `next/head` in each page for `<title>`, description and canonical; set `lang` with `<Html lang="en">` in `pages/_document.tsx`; robots.txt and sitemap.xml go in `public/` or are served by an API route.
